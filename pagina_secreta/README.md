# Our little secret — inicio para el proyecto de Lyn

## Archivos
- `index.html`: pantalla de acceso y pantallas posteriores de ejemplo.
- `style.css`: diseño rosa pastel, teclado y marcos decorativos.
- `script.js`: valida el código `170626`.
- `photos/photo1.jpg` y `photos/photo2.jpg`: coloca aquí vuestras fotos.

## Ejecutarlo en Visual Studio Code
1. Descomprime el ZIP y abre la carpeta en VS Code.
2. Pon las fotos en la carpeta `photos` con los nombres `photo1.jpg` y `photo2.jpg`.
3. Abre `index.html` con Live Server.

No necesitas instalar CSS ni JavaScript: el navegador ya los interpreta.

## Nota
La contraseña se comprueba en JavaScript del navegador. Es una barrera visual para una página romántica, no seguridad real: alguien que inspeccione el código puede encontrarla. Para privacidad real se necesita validar en un servidor.
